# Parameterized ALU

A basic ALU written in Verilog. Width is configurable using a parameter, default is 8-bit.

## Operations
- Addition
- Subtraction
- AND
- OR
- XOR
- Left Shift
- Right Shift
- Comparisons (==, >, <, >=, <=)

## Files
- alu.v - the ALU module
- alu_tb.v - testbench

## Tools
Xilinx Vivado (XSim) for simulation
